一个常见的数据场景：你收到了 50 份 PDF 格式的销售合同，需要从中提取所有客户的名称、金额和签约日期。

传统做法：打开第 1 份 -> 找到客户名称 -> 复制 -> 粘贴到 Excel -> 打开第 2 份 -> 重复以上步骤 49 次。

**50 份合同，最快也要 2 小时。而且眼睛累、手酸、容易出错。**

## PDF 处理的 3 大难题

### 1. 文本型 PDF vs 扫描件

PDF 分两种：
- **文本型 PDF**：可以直接提取文字
- **扫描件/图片型 PDF**：需要 OCR 识别

### 2. 结构化数据提取

PDF 中的表格、列表、键值对（如"姓名：张三"）需要用不同的方法提取。有些 PDF 只是看起来有表格，实际上没有表格结构。

### 3. 批量处理

一份 PDF 提取不难，难的是 50 份一起处理时保持格式统一、数据对齐。
