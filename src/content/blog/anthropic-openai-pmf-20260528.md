# Anthropic 和 OpenAI 终于盈利了？编程代理才是真正的"印钞机"

2026 年 4 月，AI 行业迎来了一个标志性时刻。Anthropic 被曝即将实现首次盈利季度，OpenAI 也在同一时期完成了关键定价改革。这不是偶然——整个行业正在经历从"烧钱抢用户"到"企业级产品变现"的结构性转变。

## 发生了什么？两大巨头的定价策略根本性转向

Anthropic 和 OpenAI 在 2026 年 4 月前后做出了一个看似"大胆"的决定：**将企业套餐从固定席位费改为按 API 调用量计费**。

具体变化如下：

- **Anthropic**：原本的 Enterprise 套餐（2025 年 8 月仍是"Claude seats 包含 typical workday 用量"），到 2025 年 11 月已悄然改为 $20/席位/月 + API 用量收费
- **OpenAI**：2026 年 4 月 2 日起，Codex 定价从按消息收费改为按 token 消耗计费，与 API 价格完全对齐
- **GPT-5.5**（4 月 23 日发布）：API 价格为 GPT-5.4 的 **2 倍**
- **Opus 4.7**（4 月 16 日发布）：API 价格约为 Opus 4.6 的 **1.4 倍**

这些变化的直接结果是：企业客户的实际使用成本从每月 $20-200/人的"全包价"，变成了按 token 消耗计费的"用水表"模式，重度用户的月均成本轻松突破 $1000。

## 编程代理（Coding Agent）才是真正的 PMF

Simon Willison 在他的博客中给出了一个非常直观的数据：

> 我订阅了 Anthropic 的 $100/月 Max 计划和 OpenAI 的 $100/月 Pro 计划。用 `ccusage` 工具测算过去 30 天如果按 API 付费的 token 消耗量，结果分别是：Anthropic Claude Code 约 **$1,199.79**，OpenAI Codex 约 **$980.37**。加起来 **$2,180.16** 的 token 用量，我只付了 $200。

换句话说，重度用户的实际消耗是订阅费的 **10 倍以上**。这解释了为什么企业客户开始"喊贵"——他们是真的在用。

### 为什么编程代理能成为突破口？

编程代理与传统聊天机器人的本质区别在于：

1. **Token 消耗量级差异** — 一次代码调试会话可能消耗数十万 token，而一次简单问答可能只需几百
2. **价值回报明确** — 工程师节省的时间直接转化为产出，ROI 可量化
3. **用户付费意愿强** — 月薪 $10,000+ 的工程师，$200/月的工具成本几乎可以忽略

## 数据验证：Uber 和 Microsoft 的"AI 账单危机"

最近关于"企业被 AI 费用吓到"的新闻中，最受关注的两个案例是 Uber 和 Microsoft。

### Uber：全年 AI 预算仅数月便耗尽

Uber CTO Praveen Neppalli Naga 指出，Uber "在 2026 年仅几个月就用完了全年 AI 预算"，主要归因于 Claude Code 的大量使用。

对此的专业解读是：Claude Code 直到 2025 年 11 月才真正好用，2025 年制定的预算无法预测 2026 年的实际需求。

### Microsoft：取消 Claude Code 许可

Microsoft 开始取消部分团队的 Claude Code 许可，表面上是鼓励工程师使用自家 Copilot CLI。但内部消息透露，这实际上是一个财务决策，指向 6 月 30 日微软财年结束的预算压力。

## SpaceX S-1 文件揭示的惊人数据

一个被广泛忽视的关键线索来自 SpaceX 的 S-1 文件：

> 2026 年 5 月，我们与 Anthropic PBC 签订了云服务协议……该客户已同意每月支付 **$12.5 亿**，持续至 2029 年 5 月……

之前 Anthropic 的 API 收入高度依赖少数大客户——据 2025 年 8 月的报道，仅 Cursor 和 GitHub Copilot 就贡献了 Anthropic 当时 $40 亿营收中的 $12 亿（占比 30%）。

如今 Anthropic 被传 Q2 营收将达到 **$109 亿**，甚至可能首次实现盈利。

## 对开发者和企业的启示

### 1. 编程代理的"黄金时代"刚开始

Claude Code / Codex / Copilot 的竞争正在推动产品快速迭代。无论你选择哪个生态，至少熟练掌握一个编程代理将是 2026 年工程师的基本技能要求。

### 2. 企业级 AI 成本管理成为新课题

当工具成本从"每人每月 $20 固定费率"变成"按 token 消耗计费"，企业的预算模型需要重构。可能出现：

- **AI 费用中心** — 每个部门的 AI 工具消耗单独核算
- **使用配额管理** — 类似云服务的成本治理机制
- **自建模型微调** — 对高频、高消耗场景进行私有化部署

### 3. 关注"November 2025 Inflection Point"

- **2025 年 11 月（November Inflection Point）** — GPT-5.1 和 Opus 4.5 的发布，让 AI 代理真正变得"有用"
- **2026 年 4 月（April Inflection Point）** — 收入层面的影响开始落地，企业的实际支付意愿被验证

## 总结

Anthropic 和 OpenAI 的"产品-市场匹配"不是通过更聪明的聊天机器人实现的，而是通过**编程代理——这个能够自动消耗大量 token、同时创造明确价值的杀手级应用**。

对于开发者来说，这个趋势带来的是机遇也是挑战：AI 工具不是越来越便宜，而是越来越"按用量付费"。学会高效使用（以及管理使用成本），将是每个人都需要面对的新课题。
