## 为什么需要 AI 写作助手？

一个普通白领每天花在"写"上面的时间有多长？

- 回复邮件：30 分钟

## 各场景最佳选择

### 日常写作场景

**推荐：Kimi** 或 **豆包**

原因：
- 完全免费，无使用限制
- 中文语境优化好
- 支持联网搜索
- 移动端体验流畅

### 专业内容创作

**推荐：Claude**

原因：
- 长文写作能力最强
- 逻辑结构最清晰
- 翻译质量最高
- Markdown 输出规范

### 技术/编程相关

**推荐：Claude** 或 **ChatGPT**

原因：
- 代码理解能力强
- 技术文档编写质量高
- 上下文窗口大（Claude 200K / ChatGPT 128K）
- API 生态完善

### 快速查阅信息

**推荐：DeepSeek**

原因：
- 完全免费
- 128K 上下文
- 速度极快
- 数学和逻辑推理能力强

## 提效技巧：Prompt 模板库

以下是我实测好用的 Prompt 模板，可以直接复制使用：

### 商务邮件模板

```
帮我写一封[场景]的邮件。
收件人：[角色]
语气要求：[正式/友好/严肃]
关键信息：
- [要点1]
- [要点2]
需要体现：[态度]
```

### 文章润色模板

```
请润色以下文字，要求：
1. 保持原意不变
2. 语言更正式/生动
3. 句子更简洁
4. 逻辑更清晰

原文：[粘贴文字]
```

### SEO 文章模板

```
请围绕关键词"{{关键词}}"写一篇 SEO 友好的博客文章。
要求：
- 字数：1500-2000 字
- 包含 H1、H2、H3 层级标题
- 关键词密度 2-3%
- 开头要有吸引力
- 结尾要有总结和行动号召
- 语言通俗易懂
```

## AI 写作的注意事项

### 优点

- **效率提升 5-10 倍**：一篇文章从构思到成稿从 2 小时缩短到 15 分钟
- **灵感激发**：AI 可以提供多个写作方向供选择
- **语法纠错**：自动检查错别字和语法问题
- **多语言支持**：快速翻译和本地化内容

### 局限性

- **需要人工审核**：AI 可能产生事实性错误
- **缺乏个人风格**：需要人工调整语气和风格
- **敏感内容把控**：AI 的价值观判断可能不适合所有场景
- **创意不足**：在真正的创意写作上 AI 仍有差距
