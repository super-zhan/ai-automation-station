# Excel 数据清洗去重完全指南：5 种高效方法（2026 最新实测）

## 写在前面

在日常数据处理中，我们经常会遇到这样的情况：导入的销售数据有几百条重复记录、从不同系统导出的客户信息大量重叠、原始数据中存在大量空行和错误值……

**数据清洗** 是数据处理中最耗时但也最关键的一步。本文从基础到高级，详解 5 种 Excel 数据清洗方法。

## 方法一：Excel 内置删除重复值（最简单）

### 操作步骤

1. 选中包含数据的任意单元格
2. 点击菜单栏 **数据** → **删除重复值**
3. 在弹出的对话框中选择需要判断重复的列
4. 点击确定，Excel 自动删除重复行

### 注意事项

- **单列去重**：效果最好，速度最快
- **多列去重**：只有当所有指定列的值都相同时才视为重复
- ⚠️ **操作不可逆**，建议先复制工作表副本备份

### 适用场景

- 数据量在 1 万行以内
- 数据结构简单（单列或少数列去重）
- 不需要精细控制保留规则

## 方法二：Power Query 高级清洗（强烈推荐）

Power Query 是 Excel 2016 以上版本内置的数据清洗神器，操作自动记录步骤，可重复使用。

### 如何进入 Power Query

**数据** → **获取和转换** → **从表格/范围**

### 常用清洗操作

#### 删除空行和空列
在 Power Query 编辑器中：
- **主页** → **删除行** → **删除空行**
- **主页** → **删除列** → **删除空列**

#### 替换错误值
将 #N/A、#VALUE! 等错误统一替换为 0 或空值。

#### 去除空格
**转换** → **格式** → **修整**（TRIM），一键清除文本前后和中间的多余空格。

#### 数据分列与合并
**转换** → **拆分列**，支持按分隔符、字符数、大写字母位置等方式拆分。

### Power Query 的核心优势

| 特性 | 说明 |
|------|------|
| ✅ 操作可回溯 | 右侧"应用的步骤"面板可随时修改 |
| ✅ 可复用 | 右键另存为查询，下次打开直接刷新 |
| ✅ 大数据友好 | 可以处理百万行级别数据 |
| ✅ 自动记录 | 所有操作自动生成 M 语言代码 |

## 方法三：Excel 函数公式去重（公式达人）

### UNIQUE 函数（Excel 365 专属）

```excel
=UNIQUE(A2:A100)
```

一键返回数据区域中的所有不重复值，支持按行/列提取。

### 标记重复项

```excel
=IF(COUNTIF($A$2:$A$100,A2)>1,"重复","唯一")
```

此公式会在重复行后面标注"重复"，方便筛选处理。

### 多条件唯一值校验

```excel
=IF(SUMPRODUCT(($A$2:$A2=A2)*($B$2:$B2=B2))>1,"重复","")
```

可以同时根据 A 列和 B 列的值判断是否重复。

### 常用清洗函数速查

| 函数 | 作用 |
|------|------|
| `=TRIM(A1)` | 去除首尾空格 |
| `=CLEAN(A1)` | 清除不可打印字符 |
| `=UPPER(A1)` / `=LOWER(A1)` | 统一大小写 |
| `=TEXT(A1,"yyyy-mm-dd")` | 统一日期格式 |
| `=SUBSTITUTE(A1,"旧","新")` | 替换指定文本 |

## 方法四：条件格式高亮重复（可视化决策）

### 操作步骤

1. 选中需要检查的数据区域
2. **开始** → **条件格式** → **突出显示单元格规则** → **重复值**
3. 选择格式样式（默认浅红色填充+深红色文字）
4. 点击确定

### 进阶：条件格式 + 筛选

1. 右键选中任意标红的单元格
2. 选择 **筛选** → **按所选单元格的颜色筛选**
3. 所有重复行一目了然，可批量删除或修改

这种方法特别适合 **数据量不大但需要人工逐条判断** 的场景。

## 常见问题解答

### Q1: 删除重复值时，Excel 保留哪一行？
Excel 默认保留第一次出现的行，删除后续重复行。不能自定义保留规则（如需保留最后一行需用其他方法）。

### Q2: 为什么我的 Power Query 打不开？
Power Query 仅支持 Excel 2016 及以上版本。Excel 2013 需要单独安装插件，2010 及以下版本不支持。

### Q3: 30 万行数据用函数会不会卡？
COUNTIF 在大数据量下会非常慢（每次计算都要扫描全表）。建议大数据用 Power Query 或在线工具。
