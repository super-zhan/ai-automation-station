## 什么是数据透视表？

数据透视表（Pivot Table）是 Excel/WPS 表格中最强大的数据分析工具。它可以在几秒钟内将成千上万行数据汇总成清晰的报表。

简单来说：**你提供原始数据，透视表自动帮你做分类汇总**。

### 一个例子说明

假设你有这样一份销售数据（1000 行）：

| 日期 | 产品 | 区域 | 销售员 | 金额 |
|------|------|------|--------|------|
| 2026-01-05 | A产品 | 华东 | 张三 | 12,000 |
| 2026-01-05 | B产品 | 华北 | 李四 | 8,500 |
| ... | ... | ... | ... | ... |

用数据透视表，3 秒就能回答这些问题：

- **各产品总销售额**是多少？
- **哪个区域卖得最好**？
- **每个销售员的业绩排名**？
- **每个月的销售趋势**？

手工做这些统计可能需要 30 分钟到 1 小时。

## 第一部分：基础操作

### 创建第一个透视表

**准备数据的要求**：
- 第一行必须是表头（列名）
- 每列数据类型一致（不要一列里混着数字和文字）
- 不要有合并单元格
- 不要有空行或空列

**操作步骤**：

1. 选中数据区域 → 快捷键 `Ctrl + A`
2. 顶部菜单 **插入** → **数据透视表**
3. 选择放置位置：
   - **新工作表**：自动创建新 Sheet（推荐）
   - **现有工作表**：放在当前页指定位置
4. 点击 **确定**

### 透视表字段布局

创建后，右侧会出现"数据透视表字段"面板，包含四个区域：

```
┌─────────────────────────┐
│     字段列表              │
│  ☑ 日期                  │
│  ☑ 产品                  │
│  ☑ 区域      ←拖拽到这里  │
│  ☑ 金额                  │
├────────────┬────────────┤
│ 行标签(R)   │ 列标签(C)   │
│ (分类维度)   │ (可选维度)   │
├────────────┼────────────┤
│ 值(V)       │ 筛选器(F)   │
│ (汇总数值)   │ (过滤范围)   │
└────────────┴────────────┘
```

**基础布局**（按产品统计销售额）：

- 行标签：将 **产品** 拖入
- 值：将 **金额** 拖入（默认自动求和）

**进阶布局**（按产品和区域交叉统计）：

- 行标签：**产品**
- 列标签：**区域**
- 值：**金额**

这样就得到了一个矩阵报表，一目了然。

### 常用汇总方式

默认是"求和"，但可以切换：

| 汇总方式 | 用途 |
|---------|------|
| 求和 | 总销售额、总成本 |
| 计数 | 订单数量、客户数量 |
| 平均值 | 客单价、平均分 |
| 最大值 | 最高销售额 |
| 最小值 | 最低销售额 |
| 乘积 | 很少用 |

**切换方法**：右键值字段 → **值字段设置** → 选择计算类型

## 第二部分：高级技巧

### 技巧 1：分组统计

**按日期分组（月/季/年）**：

1. 右键日期字段 → **组合**
2. 选择分组方式：月、季度、年
3. 确定后自动生成按月统计

**按数值分组（区间统计）**：

1. 右键金额字段 → **组合**
2. 设置起始值、终止值、步长
3. 例如：0-1000，1000-5000，5000-10000，10000+

**场景**：分析客户消费区间分布

### 技巧 2：自定义计算字段

如果需要在透视表中做计算（如利润率 = 利润/销售额）：

1. 选中透视表 → **数据透视表分析** → **字段、项目和集** → **计算字段**
2. 名称：利润率
3. 公式：`= 利润/销售额`
4. 确定

**完成后就可以在透视表中直接使用"利润率"字段了**。

### 技巧 3：切片器（交互式筛选）

切片器是数据透视表最好的搭档——它提供可视化筛选按钮。

1. 选中透视表
2. **数据透视表分析** → **插入切片器**
3. 勾选需要筛选的字段（如"区域"）
4. 确定后生成筛选面板

**优点**：
- 点击按钮即可筛选，比下拉菜单直观
- 支持多选（按住 Ctrl）
- 一个切片器可以控制多个透视表

### 技巧 4：日程表（时间筛选）

如果数据包含日期，日程表比切片器更好用：

1. 选中透视表
2. **数据透视表分析** → **插入日程表**
3. 选择日期字段
4. 可以用滑块选择时间段

### 技巧 5：美化报表

- **设计** → **数据透视表样式**：选择预设配色
- **右键** → **数据透视表选项**：关闭行/列总计、显示经典布局
- 或者直接用 WPS 的"套用表格格式"

## 第三部分：真实场景案例

### 场景 1：销售月度分析

**目标**：分析 2026 年各月各产品的销售趋势

**操作**：
1. 创建透视表
2. 行：日期 → 组合为"月"
3. 列：产品
4. 值：金额（求和）
5. 筛选器：年份 = 2026

**结果**：一张表看清全年各产品的销售走势，哪个产品增长快、哪个产品下滑一目了然。

### 场景 2：员工绩效排名

**目标**：各销售员业绩排名及占比

**操作**：
1. 行：销售员
2. 值：金额（求和）
3. 排序：右键金额 → **排序** → 降序
4. 显示占比：右键金额 → **值字段设置** → **值显示方式** → **占总计的百分比**

**结果**：自动生成排名，并显示每个人占总业绩的百分比。

### 场景 3：客户 RFM 分析

**RFM 分析**是客户分层管理的经典方法：
- **R**（Recency）：最近一次购买时间
- **F**（Frequency）：购买频率
- **M**（Monetary）：消费金额

**用透视表快速实现**：

1. 创建透视表
2. 行：客户名称
3. 值：
   - 最近一次购买日期 → 值字段设置 → **最大值**
   - 订单编号 → 值字段设置 → **计数**
   - 金额 → 值字段设置 → **求和**

4. 按这三个值对客户分类打分（需要手动添加辅助列）

## 第四部分：用 Python 实现透视表

如果你会 Python，可以用 pandas 做更灵活的透视分析：

### 基础透视

```python
import pandas as pd

# 读取数据
df = pd.read_excel('销售数据.xlsx')

# 数据透视表
pivot = pd.pivot_table(
    df,
    values='金额',
    index='产品',          # 行
    columns='区域',        # 列
    aggfunc='sum',         # 汇总方式
    fill_value=0           # 空值填充
)

print(pivot)
pivot.to_excel('透视结果.xlsx')
```

### 高级透视

```python
# 多指标 + 多种汇总
pivot = pd.pivot_table(
    df,
    values=['金额', '数量'],
    index=['产品', '区域'],
    columns='季度',
    aggfunc={
        '金额': 'sum',
        '数量': ['sum', 'mean']
    },
    margins=True,        # 显示总计
    margins_name='合计'
)
```

### 性能对比

| 数据量 | WPS/Excel 透视表 | Python pandas |
|--------|-----------------|--------------|
| 1,000 行 | 即时 | 即时 |
| 10,000 行 | 即时 | 即时 |
| 100,000 行 | 2-3 秒 | 1 秒 |
| 1,000,000 行 | 可能卡顿 | 3-5 秒 |

Excel 的数据透视表上限约 100 万行（受版本限制）。超过这个量，建议用 Python 或数据库。

## 第五部分：常见问题与技巧

### Q1：数据更新后，透视表怎么刷新？

**方法 1**：右键 → **刷新**
**方法 2**：快捷键 `Alt + F5`
**方法 3**：进入 **数据** → **全部刷新**

如果新增了行，透视表不会自动扩展数据范围。解决办法：

1. 将源数据定义为"超级表"（`Ctrl + T`）
2. 或者在 **数据透视表选项** → **数据** → **打开文件时刷新数据**

### Q2：如何取消"行标签"的默认排序？

右键 → **排序** → **其他排序选项** → 选择"手动排序"

然后就可以直接拖拽行标签调整顺序了。

### Q3：为什么透视表显示"空白"？

数据源中有空值单元格。两种处理方式：

1. 在透视表右键 → **数据透视表选项** → **设置空单元格显示为** → 输入 "0" 或 "-"
2. 在源数据中将空值填充

### Q4：如何复制透视表的结果？

直接复制粘贴会保留透视表结构。如果要复制为纯数值：

1. 选中透视表 → **复制**
2. 右键目标位置 → **粘贴数值**（`Ctrl + Shift + V`）

### Q5：能不能用公式引用透视表中的数据？

可以，用 `GETPIVOTDATA` 函数：

```
=GETPIVOTDATA("金额", A3, "产品", "A产品")
```

这个公式返回透视表中 A 产品的总金额。也可以关掉此功能：**数据透视表分析** → **选项** → **生成 GetPivotData**。
